# ObsidianOptimization 1.7.0

Minecraft 1.21.11 Fabric client optimization foundation.

Build target: Java 21, Gradle 8.14, Fabric Loom 1.17.20, Yarn 1.21.11+build.4.

This build deliberately uses only Fabric Loader APIs. It has no Fabric API dependency and no Mixins, so the previous `fabric-content-registries-v0` and Fabric API compile errors cannot occur in this project.
