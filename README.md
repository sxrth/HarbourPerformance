# ObsidianOptimization 1.8.2

Minecraft 1.21.11 Fabric client-side performance helper.

- No F8/F9 keybinds.
- Automatic performance profile on client startup.
- Adaptive render/simulation distance reduction when FPS drops.
- Mod Menu integration when Mod Menu is installed.
- Does not replace the Minecraft renderer and is designed to coexist with Sodium/Iris.

## Build

Java 21 + Gradle 8.14.

GitHub Actions uses Gradle 8.14 and Java 21.
